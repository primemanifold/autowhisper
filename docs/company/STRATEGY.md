# AutoWhisper Strategy

Last updated: 2026-05-03

## Strategic posture

AutoWhisper should not try to become a clone of Wispr Flow, Superwhisper, Otter, MacWhisper, or any single competitor. The durable wedge should be selected from evidence.

Current best wedge hypothesis:

> For privacy-sensitive desktop users and builders who need fast voice-to-text inside real workflows, AutoWhisper provides local-first dictation and transcription with transparent evidence boundaries, unlike cloud-first assistants, because the capture/inference path can run locally and the project can expose honest benchmarks, docs, and controls.

## Near-term strategy

1. **Activation first:** reduce the time and failure rate from install to first successful dictation.
2. **Trust first:** make privacy, permissions, local/cloud boundaries, and artifact validation explicit.
3. **Evidence over claims:** every platform claim should map to build, package, install, runtime, or E2E proof.
4. **Thin vertical slices:** favor small PRs that make the product more usable or more truthfully documented.
5. **Research-led table stakes:** use competitors to decide what is expected, but only implement features that reinforce the wedge.

## Differentiation candidates to validate

- Local/private transcription with no account requirement for core flows.
- Developer/operator-friendly transformations from speech into useful artifacts.
- Transparent benchmark and readiness reporting.
- Better first-run trust and permission UX than typical open-source tools.
- Cross-platform reliability that is proven rather than promised.

## Current risks

- Public messaging can overrun actual platform readiness.
- iOS may look more complete than it is without real local Whisper transcription.
- Competitor feature breadth can distract from first successful dictation.
- Local-first privacy claims need continuous audit as cloud/AI cleanup features are introduced.

## Thing to stop doing

Stop adding platform breadth without tying it to activation proof, CI proof, and honest user-facing docs.
