# Metrics

Last updated: 2026-05-03

## Activation metrics

- Time from download/install to first successful dictation.
- Permission completion rate.
- Model availability/download success rate.
- First-run error rate.

## Quality metrics

- Time to first token.
- Time to final transcript.
- End-to-end insertion latency.
- Word error rate where measurable.
- Semantic accuracy after cleanup.
- Filler-word and false-start handling.
- Correction handling.
- Punctuation and formatting quality.

## Trust metrics

- Percentage of flows with clear local/cloud disclosure.
- Audio/transcript retention clarity.
- Export/delete affordance coverage.
- Platform readiness evidence freshness.

## Current baseline status

No complete benchmark harness exists yet. Current model speed claims must be treated as repo/README claims until backed by a reproducible command, hardware profile, model hash, and sample corpus.
