# User Segments

Last updated: 2026-05-03

## Candidate segments

### Privacy-sensitive desktop professionals

Need: capture speech into text without sending sensitive audio to an unknown service.

Current alternative: Apple/Windows dictation, Superwhisper, MacWhisper, local Whisper scripts.

Activation requirement: install, model availability, microphone permissions, and first dictation must work without CLI fluency.

### Developers and operators

Need: turn spoken thought into commits, issues, docs, terminal-safe commands, and agent prompts.

Current alternative: typing, generic dictation, IDE voice input, chat voice features.

Activation requirement: dictation must handle technical vocabulary and structured transformations.

### Accessibility users

Need: reliable low-friction input with clear failure recovery and low fatigue.

Current alternative: OS dictation, Dragon-like tools, Wispr Flow, Aqua, Superwhisper.

Activation requirement: trust, latency, custom vocabulary, and corrections must be excellent. Do not market this segment before testing with the quality bar.

### Meeting/audio-file workers

Need: record/import, transcribe, search, summarize, export, and share.

Current alternative: Otter, MacWhisper, Voicenotes, meeting bots.

Activation requirement: library, speaker handling, export, and storage/privacy controls.
